# 貸付メモ

iPhone向けの貸付記録アプリです。元金・利息・返済日・メモ・写真を記録し、端末内に暗号化して保存します。サーバーやアカウントは使いません。

## 使い方

1. 公開URLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」を選びます。
2. 初回に8文字以上のパスワードを設定します。
3. 必要なら設定画面からFace IDを有効にします。利用可否は端末・Safari・パスキーの対応状況によります。
4. 「新しく記録」から貸付を登録します。貸した日は登録した日が自動で入ります。

利息は自由に入力できます。「何日ごとに利息が増えるか」を設定すると、利息欄の金額を1回あたりの利息として扱います。貸した日から返済日までに指定日数が経過した回数（`経過日数 ÷ 指定日数` の小数点以下を切り捨て）を掛け、元金と利息の合計を自動計算します。未設定なら従来どおり元金と入力した利息を足します。画面上部の計算機は、入力した利率を「1日あたり」または「1か月あたり」として、`元金 × 利率 ÷ 100 × 期間`で計算します。計算結果を記録にコピーした後も変更できます。返済日を変更すると履歴が残り、合計も更新されます。「枠の一覧」は指定の文字列を表示するだけで、計算には使いません。

## データと安全性

- 記録、日付、メモ、写真はひとつの暗号化データとしてIndexedDBに保存します。AES-GCMを使用します。
- パスワードからPBKDF2-SHA-256で鍵を作り、記録用の鍵を保護します。Face IDを設定した場合はWebAuthnのPRFを使用して同じ鍵を保護します。
- アプリのコードだけがGitHub Pagesから配信されます。貸付記録をアップロードする処理はありません。
- ブラウザデータの削除、端末の故障、パスワードの紛失で記録を失う可能性があります。設定から定期的に暗号化バックアップを書き出してください。復元にはバックアップ作成時のパスワードが必要です。
- Face ID用のパスキーは端末設定に応じてAppleの仕組みで同期される可能性があります。貸付記録そのものは同期しません。
- 端末が対応していない場合やFace ID設定が失敗した場合も、パスワードで利用できます。

## GitHub Pagesで公開

このフォルダの全ファイルをGitHubリポジトリのルートに置き、リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択します。ブランチを `main`、フォルダを `/ (root)` にして保存します。公開URLは `https://ユーザー名.github.io/リポジトリ名/` です。公開リポジトリには実際の記録やバックアップを追加しないでください。

ローカル確認は `npm run dev` でサーバーを起動し、`http://127.0.0.1:4173` を開きます。依存パッケージのインストールは不要です。
